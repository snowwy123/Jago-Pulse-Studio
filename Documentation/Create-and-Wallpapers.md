# Clearer creation and colour · Pulse 0.19.0

## Make a composition

Create starts with Track & length, then one Generate composition / Surprise me action. Choose a starting recipe or My own choices. Recipes set a real collection and film shape used by this main button: Quiet colour field uses light/atmosphere, Graphic groove uses repeating patterns, Optical journey uses optical/geometric work, and Words with breathing room uses typography. Choosing a different visual range or a named Browse family leaves the recipe route. Nothing replaces the current film until generation; Undo restores it.

All visual styles alternates flat artwork (patterns, shapes and type) with immersive scenes (worlds, water, depth and flow). These are renderer categories, not two things that need layering. Extra immersive-visual layering is OFF unless Add a second visual is checked. Locked scenes/artwork remain protected, so an intentionally locked overlay can remain. Temporary crossfades between scenes are separate from extra layers.

## Make two colours move and keep one fixed

Colour → Which colours stay still? offers four one-click presets. Primary, Secondary and Highlight have independent changes checkboxes. Choose smooth time changes, beat groups or song sections, then Apply. Scope is explicit: all unlocked scenes, this scene, or next generation only. Existing palette-role and visual locks are honoured. Save/reopen and export retain the rule. Colours are sampled from the timeline, so seeking backwards is repeatable.

This changes colour roles, not pixels inside imported images. Manually painted environment colours may remain authored. Use the advanced colour controls instead removes this simple rule from unlocked scenes and the next generation, restoring the existing journey/individual controls. A hue change cannot add saturation to a grey or white swatch; use a coloured base swatch if you want it to visibly cycle.

Pulse tunnels now use palette-toned dark surfaces and light details. Signal landscapes use continuous shaded strips, without the old checker-panel seams. Visual workshop → Look → Surface treatment chooses palette-lit or deliberately coloured wireframe. Mesh fills do not inherit the glow intended for light lines.

## Suite → Pulse → Wallpaper Engine

Send to → Suite → Pulse → Wallpaper Engine opens an in-app guide. Bring PNG artwork from Dither, Material, Repeat, World or Library. For animated artwork from Wobble/Repeat, use a PNG sprite sheet and set its rows, columns and frame rate in Pulse. Bring fonts with the artwork. Sound’s direct handoff includes audio and authored musical timing.

Other studios’ native save files are not automatically turned into Pulse layers. Export their artwork first. Video footage layers remain unsupported. Lock imported layers before generating around them.

Enable Loop, choose an appropriate screen aspect, and inspect the end meeting the start. The guide can enable a gentle end blend as an undoable edit; that does not guarantee a seamless soundtrack or every procedural simulation.

Choose MP4 for a fixed rendered video wallpaper. Choose Wallpaper Engine project ZIP for an adjustable offline web wallpaper, including artwork, renderer and editable Pulse source. Source music is excluded from the web wallpaper; desktop-audio response is optional/off by default. Speed, brightness, pixel size and linked colour roles are exposed as properties. This is a web wallpaper, not a native Wallpaper Engine scene file. Extract the ZIP and drag index.html into Create Wallpaper. If the editor recreates project.json, preserve/recreate the documented property identifiers.

Official references: https://docs.wallpaperengine.io/en/web/first/gettingstarted.html and https://docs.wallpaperengine.io/web/customization/properties . The exported runtime was tested standalone in Edge with property changes, pause and FPS settings. Actual Wallpaper Engine editor/desktop use still needs user testing.
