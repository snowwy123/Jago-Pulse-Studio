# Experimental visual instruments — Pulse 0.13.0

## Start with a track

Use **Whole-song options** to choose Varied, Clean scene cuts on beats, Chopped visual movement, or Longer flowing scenes. Cut group sets the preferred beat grouping for generated scene cuts. Include text is independent and off by default. Both whole-song buttons use these same settings. **Surprise me · whole song** generates and plays a new direction; it respects kept scenes/layers and Undo is available.

For one scene, open **Experimental visuals**, choose a Family and Look, and audition before **Apply to selected scene**. The family menu groups environments, flow/light, optical work, sculpture/architecture, travel and manual construction. **Apply to all unlocked scenes** repeats the current setup; it is different from generating a varied film.

## Make music response deliberate

**Family response** chooses a restrained band mix for space, sky, water, ribbons and interference, and a more rhythmic treatment for optical/architectural work. **Subtle flow**, **Follow the beat** and **Chop movement** provide explicit alternatives for the selected visual. Apply commits the audition.

In **Music response**, choose Family mix, Beat grid, Bass, Overall energy or High-frequency detail. Family mix gives separate bands different jobs. A single source routes that signal into the family’s response channels. Beat grid provides rhythm even in quiet passages; it is not a loudness reading and does not create sound. Signal meters help explain what is available. Signal strength boosts the input; smoothing steadies audio levels; decay controls how quickly beat accents settle. Whole-visual pulse adds a small rhythmic zoom for otherwise restrained looks.

In **Movement**, choose a quarter beat through eight beats per movement step, gate length for move-then-hold, and how strongly energy changes travel speed. **Music response → Motion timing** selects continuous travel, jump/chop or move-then-hold. These control movement clocks; light, colour and musical shape reactions may continue between steps. Flow history continues to evolve, so chopped flow is not a frozen framebuffer.

**Check / correct the song’s beat grid** opens Timing. The temporary **Return to visual audition** button restores the draft while the same project and scene still exist. Detection is an estimate: listen against the grid and use the existing correction controls where needed.

**Music response → Scene cuts on beats** reviews nearby beat-aligned boundaries for existing scenes before Apply. This keeps scene count, artwork and total duration, and uses clean cuts. Scene-relative animation follows changed scene lengths; absolute lyric times stay fixed. Unlock kept scenes first. Review again if the film or timing changes. Undo restores the earlier timing.

## Colour without losing the anchor

Use the single **Colour movement** chooser for the composition’s existing policies or continuous hue travel, an out-and-back pendulum, hue changes on beat groups, and energy-driven hue. Hue travel keeps the chosen lightness/saturation relationships. Set travel range, seconds or beat grouping as appropriate.

**Keep primary · move the others** establishes the fixed-primary/moving-accents treatment. The three Animate role switches stay authoritative, as do composition palette locks. Choose your own three colours with the existing swatches/hex fields. Each source or element still uses its assigned role; overlapping light can mix colours in the rendered image.

## Shape a world

Space/sky controls include scale, detail, inclination where relevant, star density, cloud coverage, light and an independent environment seed. Environment detail trades shader resolution against work. These are stylised original environments, not an astronomy or weather simulation.

Ringed world uses a lit, rotating sphere and a tilted ring plane with front/back occlusion and mutual shadows. Choose gas bands, ocean/cloud or mineral surfaces. Adjust axis tilt, ring opening, inner/outer radius, density, fine structure, light direction and lighting phase. Movement contains surface rotation, including reverse and zero. Rings are framed automatically as their radius changes; Scene scale gives a closer view. **Try warm planetary colours** sets an explicit three-colour override. The separate Ringed world studies project demonstrates four treatments.

## Make a visual yourself

Select **Build your own**, then add elements or an **Editable starter**. Star, arc and animated wave join the earlier shapes, text, paths and imported artwork. A starter adds editable elements to the existing design; it does not replace it. Orbit emblem, Echo rings, Wave poster and Glyph machine demonstrate different constructions.

**Look → Repeat this element** chooses a grid or radial copies. Radius uses the shorter canvas edge, so circular layouts stay circular. Turn copies around the circle or keep their orientation. **Movement → Copy motion** controls per-copy delay and size progression. Copies sample both motion and music at delayed times. Per-element spin, sway, vertical bob, travel and music controls remain available.

**Colour** offers role alternation across copies and a two-role gradient. **Finish** contains blend, opacity and relevant fill/outline choices. Imported image colours remain in the artwork; gradient controls do not recolour image pixels. Unsupported appearance controls are hidden.

Click the preview to place path points, remove the last point, close the path or smooth corners. Finish drawing before moving the element. Drag a selected element/copy or its corner; Shift keeps resize proportions and Alt bypasses placement snapping. Delete removes the selected element outside text fields. **Restore removed elements** recovers the last deletion/clear in the same scene and visual, provided there is space. It retains subsequent elements.

Click or keyboard-activate an underlined numeric value to type a precise value in the themed editor. Sliders also preview live.

## Keep and export

Use **Keep in My styles** for a named local style or **Export style** for portable parameter settings. A style references imported assets; save the **.jagopulse project** to include artwork/music. The example picker groups the new projects under **New · Experimental instruments**, near the top. The editable files are also in **Examples/Experimental instruments**.

Exact PNG/video exports use the existing export workflow. Flow seeks rebuild their fixed simulation clock; direct-time styles seek immediately. Restarting preview/history does not guarantee a seamless loop. PNG sequences are silent. Scene, layer and dimension choices still affect rendering cost. This preview does not add a shader-code editor, nested construction graph, general 3D modeller or live editable transfer from other studios.
