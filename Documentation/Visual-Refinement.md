# Visual refinement preview 0.15.0

Open **Experimental visual lab** to edit a scene's instrument. Choose its family and named look in Look, then shape its material, scenery and music response. Apply keeps the audition; Cancel leaves the scene unchanged. Use the main family catalogue for the graphic 2D looks.

## This pass

- Filament landscapes now fill the frame with layered curved terrain, valleys, crest detail and particles.
- Sculpted strata use continuous contour terraces and actual cut faces. Object fields use smooth implicit forms, contact shadows and an open winding channel. Woven passages have curved conduits, braided strands, seams and travelling light.
- Planets have finer cloud belts, local storms, shaded rings and a clearer terminator. Spiral galaxies have dust lanes and star clusters. Aurora curtains have depth folds, uneven brightness and softer veils; clouds have shaped volume and separate sea/front/haze compositions. Accretion disks have rotating filament detail rather than only a blurred halo.
- Graphic families include rebuilt cells, more detailed botanical forms, orbital instruments, woven repeats and clearer type compositions. Simple signal, wire and print looks intentionally remain available.
- Original feedback source symmetry is consistent with the selected fold. Some recipe balances were refined. Changing an input retains expanded controls and editing focus.
- Authored starter instruments contain ordinary editable parts with more purposeful assemblies. Existing paths, imported artwork, text and manual editing remain available.
- Finish detail for environment renderers supports up to a 3840-pixel source edge, within the device limit. Stateful feedback keeps its separate bounded simulation size. Higher detail is more expensive; it is not required for every visual.
- Local preview quality changes editing copies only. Light reduces both pixels and expensive mesh detail; exports retain authored detail. Pixel-world outputs preserve proportions when changing aspect ratio.

## Reviewing a look

Try a single scene first, then a complete track. Compare restrained and strong reactions, fixed and moving colour roles, slow travel, beat holds, and an intentionally still version. Changes should suit the instrument: a cloud need not bounce like a drum meter.

The development evidence covers still inventories, selected sequential frames against two actual track analyses, saved editing, deterministic seeking, signal/off routing, model checks and actual PNG/MP4 exports. It does not establish independently listened beat accuracy or performance on a physical low-end PC. Some looks remain deliberately abstract; this is an experimental development preview, not a claim of photorealistic simulation or equal artistic maturity throughout the catalogue.
