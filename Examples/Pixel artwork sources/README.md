# Pixel artwork source workshop

Open .jago in Wobble to paint over or replace the separate scenery/foreground images and edit the small native light animation. The base scenes are imported bitmap layers, not separately editable objects.

Open .jagodither in Dither to adjust its restrained palette finish. PNGs and four-frame sprite sheets are the exported artwork. Open .jagopulse in Pulse to use that animated artwork as an ordinary editable image layer; add your music and other visuals. The pixel-world instruments remain available separately for fully procedural colour and movement.

These source projects are deliberately small and offline. They demonstrate Wobble -> Dither -> Pulse exchange rather than claiming automatic round-trip editing.
