# Jago Pulse 0.11.3

Art, rhythm and motion.

Create music-driven films, visualisers, animated posters and ambient backdrops. Generate source-free visuals or use your artwork, music and fonts, then refine an editable composition.

[Website](https://jagosuite.co.uk/) · [Downloads](https://github.com/snowwy123/Jago-Pulse-Studio/releases/latest)

## Get started

Download **Jago-Pulse-v0.11.3.zip**, right-click it and choose **Extract All**. Open **Jago-Pulse.exe** from the extracted folder. Keep supporting files together. No installer is needed for the portable edition. Open **Jago-Pulse.html** for offline browser use in current Edge or Chrome.

Windows requires 64-bit Windows and .NET Framework 4.8. Windows studio hosts require Microsoft Edge WebView2 Runtime.

Read **Documentation/Jago-Pulse-Guide.pdf** for an illustrated introduction, tools and connected workflows. Save editable projects as well as finished exports.

## Tools

- 47 visual families with 141 named looks in six collections.
- Seeded generation, compare-three alternatives, recipes, protected edits and saved directions.
- Layer stacks, masks, groups, precise motion channels and scene timing.
- Local music analysis, grid audition/correction, attacks, frequency and energy signals.
- Palette roles, evolving colour journeys, finishing filters and custom dimensions.
- Music-led film shapes create contrast, breathing room, recurring motifs and endings.
- Family-specific reactions, slower drift and fixed-centre or moving-perspective styles.
- Surprise me explores palette and cut choreography while respecting locks.
- Generated words have a separate switch; manual scene text and timed lyrics stay distinct.
- Import/edit lyric cues and optionally draft English words using the local transcription pack.
- Editable Workscape tabs preserve the composition and embedded assets.
