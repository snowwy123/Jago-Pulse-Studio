# Jago Pulse

Make something move with the music.

Turn a soundtrack into a visual composition, or build a scene from your own artwork, words and motion. Choose when to follow the beat and when to let a visual breathe.

## Give it a try

Install with Jago Suite, or extract the portable download and open **Jago-Pulse.exe**.

Add a track and generate a composition. Browse visual families, keep a direction you like, then refine the timing, colour and motion before exporting.

[Find Jago Suite and downloads](https://jagosuite.co.uk/)
