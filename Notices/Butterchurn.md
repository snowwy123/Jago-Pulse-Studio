# Experimental Butterchurn visuals

Butterchurn 2.6.7 and Butterchurn Presets 2.4.7: copyright (c) 2013-2018 Jordan Berg, MIT licence. Full notices are retained beside this file and embedded in the offline page.
Engine: https://github.com/jberg/butterchurn
Preset package: https://github.com/jberg/butterchurn-presets
Pinned npm packages: butterchurn@2.6.7, butterchurn-presets@2.4.7.
Six presets were selected from the package's minimal collection. Original artist names are retained in the selector and source. The package distributes these under MIT; this is the package's stated licensing, not an independent audit of each artist's history. Review provenance again before any public release.
Four additional feedback looks and all projected-depth geometry are original Pulse code. No private tracks or remote dependencies are bundled. No downloaded preset-code import is exposed to project files.
Feedback renders local decoded audio samples through a bounded WebGL 2 renderer. Unavailable WebGL falls back to the original scene with a visible lab diagnostic. Preview/still PNG and real-time opaque WebM recording are supported. Seeking uses a bounded warm-up, not a faithful reconstruction of preceding feedback. Exact-frame feedback exports remain blocked. Depth families remain stateless and use ordinary exact exports.
